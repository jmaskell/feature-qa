# Copy rules

1. Use sentence case for headings, buttons and labels. Only proper nouns keep their capitals.
2. Use plain words. Write "use", not "utilise".
3. Do not write "please" or "sorry".
4. A button says what it does: a verb and an object, for example "Add property".
5. Keep a button label to four words or less.
6. Show an empty value as "None".
7. Write money as "£950 a month".
8. Do not show a code, an id or a field name to the person.
