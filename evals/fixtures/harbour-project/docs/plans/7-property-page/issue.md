# 7. Property page

Outcome: a letting agent can see the facts of one property and contact its tenant, without personal data leaving the page.

## Acceptance criteria

- [ ] The properties list shows each property with its address, rent and status.
- [ ] The property page shows the address, the monthly rent and the status of the property.
- [ ] On a let property, the agent sees the tenant's name and phone and can open a message dialog. On a vacant property, the tenant section says "None".
- [ ] The tenant's name, email and phone never show in the page title, the URL or browser storage.
