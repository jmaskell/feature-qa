# Plan A: qa-kit and the lettings fixture app

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the scripted QA checks as a TypeScript library on Playwright, and a fake-company app with one planted defect for each check, so each check is proven to fail on its defect and to pass on the clean app.

**Architecture:** An npm workspace with two packages. `packages/qa-kit` holds pure rule functions (unit-tested with Vitest) and thin page collectors that run in the browser (tested with Playwright). `fixtures/lettings-app` is a plain Node HTTP server with no dependencies. It renders HTML strings, and a `?defect=<id>` query (or a `qa_defect` cookie) switches on one planted defect. A registry maps each defect id to the check id that must catch it. A matrix test proves the mapping.

**Tech Stack:** Node 24, TypeScript 5 (strict, ESM), `@playwright/test` 1.63, `@axe-core/playwright` 4, Vitest 4.

**Spec:** `docs/spec.md`

## Global Constraints

- Nothing in `packages/qa-kit` names a project, a brand, a design system or an identity provider. Project facts come only from the `QaConfig` adapter.
- `packages/qa-kit` has two runtime dependencies at most: `@axe-core/playwright`, and `@playwright/test` as a peer dependency.
- `fixtures/lettings-app` has no npm dependencies. It uses `node:http` only.
- Every fixture value is fake. Emails end in `@example.test`. Phones use the UK drama range `07700 900xxx`.
- Each check is red on its planted defect and green on the clean app. A check without a planted defect is not merged.
- A check returns findings. It never throws for a defect. It throws only for a broken call (for example, no page).
- Markdown and code comments use Simplified Technical English: one idea in one sentence, active voice, plain words.
- Commit messages end with: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`

## Review Focus

1. **A check that passes on everything.** A rule with a bug that never fires looks the same as a clean page. Pinned in Task 12: the matrix test runs each defect and asserts that its check reports at least one `fail`, and that the clean app reports zero `fail` for every check.
2. **A check that fires on the wrong defect.** A noisy check (for example, layout fires on every page) makes the owner ignore the report. Pinned in Task 12: for each defect, only the expected check (and checks listed as allowed side effects in the registry) report `fail`.
3. **Hidden elements.** A rule that reads `display:none` or off-screen text reports defects the person cannot see. Pinned in Tasks 3, 5 and 6: each collector test includes a hidden element with a defect and asserts no finding.
4. **Many findings of one kind.** One missing style on a list of 200 rows must not make 200 findings that bury the rest. Pinned in Task 2 (`dedupe`): findings with the same check, rule and selector pattern collapse to one with a count.
5. **Seed values inside harmless text.** The leak scan must not flag "Ann" inside "Annual". Pinned in Task 9: values match on word boundaries, and values shorter than 4 characters are ignored.

```ts
  | "conformance" | "leaks" | "access" | "coverage";
export type Severity = "fail" | "warn";

  rule: string;            // short kebab id, e.g. "doubled-punctuation"
  severity: Severity;
  message: string;         // one sentence, no personal data
  selector?: string;       // CSS path of the element, when there is one
  sample?: string;         // at most 80 characters of the text that broke the rule
  count?: number;          // set by dedupe()
  route?: string;
  state?: string;
  viewport?: string;
}
export interface Role { name: string; signIn?: (page: import("@playwright/test").Page) => Promise<void>; }
export interface Scenario { name: string; states: string[]; knownValues: string[]; }
export interface DesignSystemRules {
  componentMarker: string;                 // CSS selector that matches a design-system component root
  interactiveSelector?: string;            // default: "a[href],button,input,select,textarea,[role=button]"
  maxVariants?: Record<string, number>;    // component name → allowed variants

  bannedTerms?: string[];
```

```ts
import { dedupe, finding, hasFailures, selectorPattern } from "../../src/findings.ts";

describe("findings", () => {
  it("trims a sample to 80 characters", () =>
    expect(finding({ check: "copy", rule: "r", severity: "fail", message: "m", sample: "x".repeat(200) }).sample).toHaveLength(80));
  it("collapses one rule on many rows into one finding with a count", () => {

      finding({ check: "interaction", rule: "pointer-cursor", severity: "fail", message: "m", selector: `ul > li:nth-child(${i + 1}) > button` }));
    const out = dedupe(rows);
    expect(out).toHaveLength(1);
    expect(out[0]?.count).toBe(200);
  });
  it("keeps different rules apart", () =>
    expect(dedupe([
      finding({ check: "copy", rule: "a", severity: "fail", message: "m" }),
      finding({ check: "copy", rule: "b", severity: "fail", message: "m" }),
    ])).toHaveLength(2));
  it("removes nth-child from a selector pattern", () =>
    expect(selectorPattern("main > ul:nth-of-type(2) > li:nth-child(3)")).toBe("main > ul > li"));
  it("finds failures and ignores warnings", () => {
    expect(hasFailures([finding({ check: "copy", rule: "a", severity: "warn", message: "m" })])).toBe(false);
    expect(hasFailures([finding({ check: "copy", rule: "a", severity: "fail", message: "m" })])).toBe(true);
  });
```

```ts
import type { Finding } from "./types.ts";

export function finding(f: Finding): Finding {
  return f.sample === undefined ? f : { ...f, sample: f.sample.slice(0, 80) };
}

export function selectorPattern(selector: string): string {
  return selector.replace(/:nth-(child|of-type)\(\d+\)/g, "");
}

export function dedupe(findings: Finding[]): Finding[] {
  const groups = new Map<string, Finding>();
  for (const f of findings) {
    const key = [f.check, f.rule, f.severity, f.route ?? "", f.state ?? "", f.viewport ?? "", selectorPattern(f.selector ?? "")].join("|");
    const seen = groups.get(key);
    if (seen) seen.count = (seen.count ?? 1) + 1;
    else groups.set(key, { ...f });
  }
  return [...groups.values()];
}

export function hasFailures(findings: Finding[]): boolean {
  return findings.some((f) => f.severity === "fail");
}
```

```ts
import type { QaConfig } from "./types.ts";

export function defineQaConfig(config: QaConfig): QaConfig {
  if (!/^https?:\/\//.test(config.baseURL)) throw new Error("baseURL must start with http:// or https://");
  const roles = new Set<string>();
  for (const r of config.roles) {
    if (roles.has(r.name)) throw new Error(`roles: ${r.name} is listed twice`);
    roles.add(r.name);
  }
  for (const [route, byRole] of Object.entries(config.accessMatrix)) {
    if (!config.routes.includes(route)) throw new Error(`accessMatrix: route ${route} is not in routes`);
    for (const role of Object.keys(byRole)) {
      if (role !== "anonymous" && !roles.has(role)) throw new Error(`accessMatrix: role ${role} is not in roles`);
    }
  }
  return config;
}
```
